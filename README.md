# LangChain AI Agent Application

An intelligent AI Agent application built using LangChain, Google Gemini API, and Streamlit.

## Features
- Interactive user interface built with Streamlit.
- Integration with Google Gemini LLMs via LangChain.
- Dynamic prompt management using LangChain Prompt Templates.

## Setup and Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/ach690347-hu/langchain-agent-app.git
   cd langchain_project

   Install Dependencies:

Bash
pip install -r requirements.txt

Create a .env file in the root directory and add your Google Gemini API key:
